# Performance/Debug Overlay for Bevy UI

This is a fork of [github.com/IyesGames/iyes_perf_ui](https://github.com/IyesGames/iyes_perf_ui) because the core maintainer, [inodentry](https://github.com/inodentry), was unable to keep maintaining the project for personal reasons and no one has been given access to maintain.

This repository contains a performance/debug overlay for the [Bevy game engine](https://bevyengine.org).

It is commpatible with Bevy `0.19`.

For more information see [github.com/IyesGames/iyes_perf_ui](https://github.com/IyesGames/iyes_perf_ui).
