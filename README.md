# Performance/Debug Overlay for Bevy UI

This is a fork of [github.com/IyesGames/iyes_perf_ui](https://github.com/IyesGames/iyes_perf_ui) because the core maintainer, [inodentry](https://github.com/inodentry), was unable to keep maintaining the project for personal reasons, leaving the repository unmaintained since early 2025.

iyes_perf_ui is a performance/debug overlay for the [Bevy game engine](https://bevyengine.org). I use it in [github.com/kimgoetzke/procedural-generation-2](https://github.com/kimgoetzke/procedural-generation-2).

It is compatible with Bevy `0.19`.

For more information see [github.com/IyesGames/iyes_perf_ui](https://github.com/IyesGames/iyes_perf_ui).
